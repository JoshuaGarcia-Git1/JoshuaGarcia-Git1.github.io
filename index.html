GESTORPRO

Sistema de Gestión Comercial

Sistema web completo para una tienda de ropa y accesorios. Gestiona inventario, registra ventas, administra empleados y controla acceso por roles diferenciados.

Construido en PHP puro con MySQL sobre XAMPP. Autenticación con cifrado bcrypt, protección contra SQL injection y XSS, dashboard con gráficos de ventas en tiempo real y precios en guaraníes paraguayos. Cero frameworks externos.
